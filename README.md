## 현장 적용 계획

제조기 3대의 운전값과 시각을 생산 LOT에 연결한다. 시스템이 위험 설비와 LOT를 표시하면 작업자가 해당 제품을 점검하고, 품질 담당자가 검사 결과와 보류·해제 사유를 기록한다.

| 기간 | 주요 작업 |
| --- | --- |
| 1~2개월 | 계측 범위와 생산 LOT 연결 기준 확정 |
| 3~4개월 | 생산 이력 연계 및 조기경보 모델 시범 적용 |
| 5~6개월 | 별도 LOT로 모델 검증, 작업자 교육 및 인수 |

## 예산과 성과 목표

총사업비 **3억 8,000만 원**은 정부 1억 9,000만 원, 기업 현금 1억 7,000만 원, 기업 인건비 현물 2,000만 원으로 편성한 교육용 예산안이다.

| 지표 | 착수 전 3개월 기준 | 구축 목표 |
| --- | --- | --- |
| 공정 불량률 | 5.00% (가상 원장 기준 300만 개 중 최초 불량 15만 개) | 4.00% |
| 성형 전력 원단위 | 개당 0.030 kWh (설비 정격과 가동시간으로 추정) | 개당 0.020 kWh |

월 100만 개 생산을 유지하고 두 목표를 모두 달성하면, 교육용 단가 기준으로 불량 손실 회피 월 100만 원과 전력비 절감 월 150만 원을 예상한다. 합계 **월 250만 원**은 운영·유지보수비 차감 전 추정치다. 전력 효과를 검증하려면 성형기 전용 계량기로 기준값을 먼저 측정해야 한다.
